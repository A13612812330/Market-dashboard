# 跨电脑部署

本项目以本地运行优先。行情缓存、模拟账户、策略、消息配置均保存在本机 `data/`，不会随 GitHub 同步。

## 需要准备

| 项目 | 是否必须 | 用途 |
| --- | --- | --- |
| Git 或 Codex | 必须 | 下载项目 |
| Node.js 22 或更高版本 | 必须 | 运行本地服务和 SQLite |
| Python 3.10 或更高版本 | 建议 | 拉取行情、历史 K 线和公告 |
| Futu OpenD 与行情权限 | 可选 | A 股、ETF 的实时行情和订阅增强 |
| AI 接口 | 可选 | 风险雷达、报告整理和文字分析 |
| 飞书或钉钉配置 | 可选 | 本地定时通知 |

## 用 Codex 从 GitHub 安装

在 Codex 新任务中直接输入：

```text
从 GitHub 克隆 A13612812330/Market-dashboard 到 E:\新建文件夹\Codex-GPT\tools，按 README 安装依赖、复制 .env.example 为 .env、不要写入任何真实密钥，然后启动并检查 http://127.0.0.1:5190。
```

如果仓库为私有仓库，需要在新电脑的 Codex 中登录拥有仓库权限的 GitHub 账号。

## 手动安装

```powershell
git clone https://github.com/A13612812330/Market-dashboard.git
cd komo-market-dashboard
npm ci
python -m pip install -r requirements.txt
Copy-Item .env.example .env
npm start
```

浏览器访问 `http://127.0.0.1:5190`。

## 首次配置

1. 打开 `.env`，至少修改 `ADMIN_USERNAME`、`ADMIN_PASSWORD`。
2. 没有 Futu OpenD 时，把 `FUTU_ENABLED=0`；系统会使用公开源和本地缓存，不会伪造实时数据。
3. 要使用 Futu 时，安装并登录 Futu OpenD，保持 `FUTU_HOST=127.0.0.1`、`FUTU_PORT=11111`。
4. 需要 AI 时填入 `AI_API_KEY`、`AI_MODEL`、`AI_BASE_URL`；不配置 AI 不影响行情和模拟交易。
5. 需要消息通知时再填飞书或钉钉字段；未配置时不会发送外部消息。

## 首次拉取数据

```powershell
npm run collect
```

首次历史 K 线补齐会较慢。建议先启动页面，再按需要从研究中心或模拟操作中补历史数据，避免一次拉取过多标的。

## 数据迁移

新电脑默认从空数据库开始。若需要迁移个人数据，只在受控设备间复制旧电脑的 `data/` 文件夹；其中包含账户、策略、缓存和通知配置，不能上传 GitHub 或发给他人。

## 常见检查

```powershell
npm run check
npm run check:frontend
python -m py_compile scripts\collect_market_data.py
```

Futu 未启动时，设置页会显示连接状态。自动模拟交易只在 A 股交易时段、且所需行情在 5 分钟内时运行；它不会调用 Futu 的下单、撤单、账户或持仓接口。
