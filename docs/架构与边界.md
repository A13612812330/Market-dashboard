# 架构与边界

## 模块

| 模块 | 内容 | 数据或依赖 |
| --- | --- | --- |
| 首页 | A 股指数、ETF、板块、趋势图、资讯摘要 | Futu OpenD 优先，公开源和 SQLite 缓存兜底 |
| 条件筛选 | 股票和 ETF 的多条件筛选、预设模板、研究评分 | 行情快照、历史 K 线、本地规则 |
| 行情自选 | 分组管理、自选行情、K 线、完整研究 | 自选表、行情、历史数据 |
| 研究中心 | 定时市场报告、风险雷达、单票研究和技术指标 | WorkBuddy 报告目录可选、本地数据、AI 可选 |
| 模拟操作 | 多账户、策略、持仓、资金曲线、操作日志、自动模拟 | SQLite、行情缓存、策略规则 |
| 用户管理 | 本地账号和成员模拟账户查看 | 管理员权限、本地 SQLite |
| 设置 | 数据源、刷新、维护、容量和通知状态 | 本地配置与维护日志 |

## 数据流程

```text
Futu OpenD / 公开数据源
  -> 本地采集与缓存
  -> SQLite 历史与快照
  -> 看盘、筛选、研究、自选
  -> 本地模拟策略与日志
```

AI 只用于报告整理、风险文字解读和可选内容生成。行情数字、涨跌幅、成交额、策略条件和模拟订单均由真实缓存或本地规则产生。

## 明确边界

- 只做本地模拟交易，不调用 Futu 下单、撤单、账户或持仓接口。
- 缺少真实行情或历史数据时显示缓存、最近数据或暂无数据，不生成假行情。
- 不上传 `data/`：其中可能包含账户、策略、缓存、消息配置和个人研究记录。
- 不提交 `.env`、机器人 Webhook、AppSecret、Token 或管理员密码。
- 海外市场作为辅助指数观察，不作为模拟交易的主要数据范围。
- 自动策略仅供研究和本地模拟，不代表投资建议或收益承诺。
